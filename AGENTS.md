# Repository: Game-Theory Experiment Simulation

## Project Purpose
Synthetic data layer and game definitions for a canonical game-theory
experiment repository comparing human and LLM decision-making behaviour.

## Directory Layout
```
src/
  games.py          – GameDef dataclass + 8 game registrations + accessors
  agents.py         – simulate_human_decision / simulate_llm_decision
  metrics.py        – pre-existing statistical metrics (Cohen's d, etc.)
  structural_tests.py – pre-existing structural test functions
  visualization.py  – pre-existing visualisation helpers

data/
  generate_data.py  – generate_exp1_data / generate_exp2_data / generate_exp3_data
  exp1_data.csv     – 156 000 rows  (canonical games, generated by main())
  exp2_data.csv     –  36 000 rows  (novel games, generated by main())
  exp3_data.csv     –  27 000 rows  (individuation gradient, generated by main())

exp/
  exp_1_canonical.py, exp_2_novel.py, exp_3_moderator.py – analysis scripts

tests/
  test_games.py, test_experiments.py, test_metrics.py, test_structural_tests.py
```

## Key Design Decisions

### GameDef (src/games.py)
- Primary field name is `y_strategic` (not `benchmark_y_strategic`).
- `benchmark` and `benchmark_y_strategic` are **properties** (aliases) for
  backward-compatibility with downstream code.
- `payoff_fn` uses `field(compare=False, repr=False)` so GameDef remains
  comparable and hashable by data fields only.
- Registry `_GAME_REGISTRY` preserves insertion order (Python 3.7+).

### Agent Simulators (src/agents.py)
- stag_hunt is handled as a Bernoulli game throughout; all other games use
  continuous Gaussian draws clipped to [action_min, action_max].
- For stag_hunt LLM: cooperation inclination drawn from N(y_strategic, spread)
  clipped to [0,1] gives the Bernoulli probability.
- Path dependence: `y = 0.4 × prev_decision + 0.6 × base_draw`; for stag_hunt
  this operates at the probability level before Bernoulli sampling.
- Paraphrase noise is skipped entirely when `paraphrase_id == 0` (no extra RNG call).

### Data Generation (data/generate_data.py)
- `_collect_condition()` is the shared inner loop; it handles sequential round
  path-dependence by tracking per-agent `prev` anchors (mean of previous batch).
- `n_human` / `n_llm` are **per-condition-per-round** observation counts.
- Experiment 1 rows ≈ 156 000; Experiment 2 ≈ 36 000; Experiment 3 ≈ 27 000.
- CSV files are written to the same directory as generate_data.py (`DATA_DIR`).
- `sys.path.insert(0, ...)` in generate_data.py allows direct execution from
  any working directory.

## Pre-existing Test Failures (unrelated to this layer)
`test_metrics.py::test_cohens_d_known` and `test_metrics.py::test_classify_noise`
fail due to sign-convention and classification-threshold issues in the
pre-existing `src/metrics.py`.  `test_structural_tests.py` errors because its
fixture `df` is defined inside `src/structural_tests.py` (not in conftest.py).
These were failing before the data layer was added.

## Running the Data Layer
```bash
python data/generate_data.py          # generates all three CSVs
pytest tests/test_games.py tests/test_experiments.py   # 11/11 pass
```
