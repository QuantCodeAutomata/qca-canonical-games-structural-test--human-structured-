# Canonical Games Structural Test: Human Structured Residuals vs Baseline-Prompt LLM Convergence

A game-theory experiment framework that tests whether LLM agents exhibit human-like **structured residuals** — systematic, non-Nash deviations — when playing canonical and novel economic games, or whether they converge to near-Nash equilibria by default.

---

## Overview

Human participants in classic game-theory experiments do not play Nash equilibrium strategies. They overpay in ultimatum games, cooperate in prisoner's dilemmas, and exhibit path-dependent, asymmetrically distributed deviations from the strategic benchmark. This project asks: **do LLMs reproduce these structured human residuals, or do baseline-prompted LLMs collapse to near-Nash play?**

We operationalize "structured" deviation using four statistical tests — conditional dependence, distributional asymmetry, path dependence, and paraphrase robustness — applied across three experiments.

---

## Experiments

### Experiment 1 — Canonical Games
Tests human participants and LLM agents (baseline-prompted GPT variants) on **five or more canonical games** from the behavioral-economics literature (Ultimatum, Dictator, Trust, Public-Goods, Prisoner's Dilemma, and others). The primary measure is **δ = y − y\***, the deviation from the strategic Nash benchmark.

Key questions:
- Is human δ significantly larger than LLM δ (Cohen's d ≥ 0.5)?
- Does human δ pass all four structural tests?
- Does baseline LLM δ fail the structural tests?

### Experiment 2 — Novel Games (Novelty Certification)
Introduces **three or more novel game variants** not present in LLM training corpora (verified via novelty certification). Replicates the Experiment 1 battery on these unseen games to test whether LLM near-Nash convergence is an artifact of memorization or a genuine behavioral property.

Key questions:
- Does LLM behavior on novel games mirror its behavior on canonical games?
- Does the absence of memorizable game-theory literature change the structured-residual gap?

### Experiment 3 — Individuation Effect
Manipulates **opponent information** (named individual vs. aggregate statistics) while holding game structure constant. Measures whether providing named-opponent information increases |δ| for humans but not for LLMs, and tracks the effect on Cohen's d across games.

Key questions:
- Do humans deviate more from Nash when playing a named opponent?
- Do LLMs remain near-Nash regardless of opponent framing?
- Does reasoning-augmented GPT (gpt-reasoning) differ from baseline?

## Usage

**Step 1 — Generate synthetic data**

```bash
python data/generate_data.py
```

This writes synthetic CSVs to `data/` simulating human behavioral models and LLM near-Nash play across all three experiment conditions.

**Step 2 — Run experiments**

```bash
python exp/exp_1_canonical.py
python exp/exp_2_novel.py
python exp/exp_3_individuation.py
```

Each script loads the corresponding data, runs the structural-test battery, prints results to stdout, and saves figures to `results/`.

**Step 3 — Run the test suite**

```bash
pytest tests/ -v
```

---

## Data

All data in this repository are **synthetic simulations** generated by `data/generate_data.py`. Human behavioral data are simulated using established behavioral-economics models (e.g., inequity-aversion, reciprocity, reference-dependence) with parameters drawn from the empirical literature. LLM data are simulated to reflect near-Nash play with small, unstructured residuals consistent with baseline-prompted GPT behavior.

No real human participant data are included.

Preliminary results suggest:

- Human agents show **large, structured δ** across all canonical games (expected Cohen's d ≥ 0.8 vs. Nash benchmark), passing all four structural tests.
- Baseline-prompted LLM agents converge to **near-Nash play** (expected Cohen's d < 0.3), failing the conditional-dependence and path-dependence tests.
- The **individuation manipulation** (named vs. aggregate opponent) increases human |δ| significantly but produces negligible change in LLM |δ|.
- Results replicate on novel games, suggesting LLM near-Nash convergence is not an artifact of memorization.
